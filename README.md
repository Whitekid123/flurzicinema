# Flurzi Cinema

A Next.js/React public cinema website with an original Flim-style editorial homepage, connected discovery/movie/series catalogs, title details, collections, premieres, features, membership preview, About, Contact, Help and draft legal pages.

The homepage uses the neutral cinematic palette, full Flurzi Cinema masthead, varied pointer-revealed images, falling film cards, working search, measured GSAP Flip assembly, floating genre labels, selectable Cinema Vault and four scroll-driven feature demos. The final image opens and closes like a door. The hero is unpinned; desktop falling, mosaic and feature scenes are capped at 620/720/950px. Mobile and reduced-motion layouts use normal flow. See [the motion follow-up report](docs/MOTION_FOLLOWUP_REPORT.md) and [recorded walkthrough](docs/motion-followup/motion-walkthrough.webm).

The user confirmed that an API key was not obtained and will be added later. Five fictional titles remain paired with their own original concept artwork. The source-neutral server catalog adapter is ready for approved real metadata/artwork. Streaming, authentication and payments are separate future integrations.

## Run locally

Requires Node.js 20.9+ and npm. In this workspace, prefix shell commands with `rtk` per the user instructions.

```sh
rtk proxy npm.cmd install
rtk proxy npm.cmd run dev
```

Open http://127.0.0.1:3000. Use `npm` instead of `npm.cmd` outside Windows.

```sh
rtk proxy npm.cmd run typecheck
rtk proxy npm.cmd run lint
rtk proxy npm.cmd run build
rtk proxy npm.cmd start
rtk proxy npm.cmd run test:e2e
```

Browser tests require an existing server at port 3000. The checkout defaults to its installed Playwright Chromium headless shell; set `CHROME_PATH` on other systems.

After building, `rtk proxy node scripts/production-qa.mjs --timeout=120000` runs the complete production browser suite, current motion screenshots and a recorded walkthrough. It starts an owned server at port 3002 and stops it afterward. `--skip-capture` runs tests only. `PLAYWRIGHT_BASE_URL` selects an existing test server; `PREVIEW_URL` selects a capture server. Public-route captures are generated by the tests; `scripts/public-contact-sheets.mjs` composes their overview sheets.

## Structure

- `app/`: App Router pages, metadata and route states.
- `components/home/`: editorial homepage, Vault and local feature controls.
- `components/motion/useEditorialMotion.ts and useFeatureJourney.ts`: current homepage GSAP/ScrollTrigger/Flip/SplitText lifecycle.
- `components/public/`: shared catalog, detail, forms, help, pricing and public-page motion.
- `components/layout/`, `components/ui/`: shared navigation, footer, accessible dialogs and artwork fallback.
- `lib/catalog/`, `types/public.ts`: normalized backend contracts, rights-aware adapters and server-only provider.
- `styles/editorial*.css`: scoped neutral homepage system; existing public route styles stay independent.
- `public/`: original local film artwork and open-licensed Manrope font.
- `tests/`: current catalog, homepage, editorial motion and public-site regression checks.
- `docs/rollback/pre-final-homepage/`: source and superseded 3D/camera tests from the prior homepage.
- Older exhibition/Three.js motion modules remain available for history but are not mounted by the redesigned homepage.

Saved stories use `flurzi-saved-demo`; premiere reminders use `flurzi-local-reminders` and send no notifications. Feature demos run locally. Contact inquiries are reviewed in memory without sending or saving. No credentials or payments are collected.

To integrate an approved catalog, configure `FLURZI_CATALOG_API_URL` and optional private `FLURZI_CATALOG_API_TOKEN` before building. The server reads `GET {base}/titles`; client components never receive credentials. Rebuild/restart after source changes. Copy `.env.example` to a local configuration file and set `NEXT_PUBLIC_SITE_URL` to the actual origin before deployment. Never prefix private tokens with `NEXT_PUBLIC_`.

The preview remains `noindex` until content, policies and launch details are approved. No public deployment was performed.
