# Flim integration plan

The existing Next.js homepage is the foundation. No routes, fictional catalog entries, dialogs, saved-story behavior, navigation, pricing disclosures, or feature demos will be removed.

## Preservation and baseline

This checkout has no `.git` repository (`git status` reports that fact). The rollback point is therefore a byte-for-byte copy of the current source, configuration, lockfile and assets at `docs/rollback/pre-flim-integration`, with SHA-256 checksums in `SNAPSHOT.json`. Restore individual files from that folder when needed; do not overwrite later unrelated work. No Git reset, clean, stash, or initialization was used.

At baseline, CinemaHome composed CinemaHero, FeaturedExhibition, Manifesto, VaultExperience, FeatureLab, premiere, membership, FAQ, final invitation, Header/Footer and Modal. useExhibitionMotion owned the pinned opening, title docking, poster paths, manifesto lighting, premiere drift and pointer parallax. VaultExperience already used Flip for selection, spread and Timeline/Grid transitions. The baseline atmospheric canvas was only 2D dust; it did not meet the new immersive-background requirement. The final implementation and test results are in `FLIM_INTEGRATION_REPORT.md`.

Baseline screenshots are at `docs/flim-before` at 1440, 1024, 768 and 390 pixels. The first normal-motion desktop opening was captured, but subsequent animated desktop captures stalled. The repeatable comparison uses reduced motion at identical positions; separate normal-motion sequences will verify the new animation. This pre-existing renderer issue must be resolved or clearly reported, not concealed by increased test timeouts.

## Reference evidence

- [Flim](https://flim.ai/): fresh browser traversal of all major desktop and mobile sections and reverse scrolling, saved under `docs/flim-reference`. Earlier fine-grained motion observations remain under `docs/rescue-reference`. Public behavior and the creators' explanation are evidence; no source or media will be copied.
- [Full ToyFight case study](https://tympanus.net/codrops/2026/01/14/a-site-for-sore-eyes-combining-gsap-and-webflow-to-showcase-flim/): read in full. It explains per-cycle interruptible hero timelines, responsive SplitText line masks, character opacity waves, Flip image-to-interface relocation, pinned horizontal scroll with matchMedia, DOM/Rapier physics, visibility-paused loops and repeating-mask page transitions.
- [Trinity](https://trinity.fantik.studio/): repeated direct attempts have not yielded a usable body. Its original camera choreography has not been verified. The environment below is an original implementation of the user's specified depth, lighting, motion and camera requirements, not a claim of pixel-accurate reproduction.
- [Van Morrison](https://vanmorrison.com/music) and [Avalon](https://links.avalonplatforms.com/): preserve the already researched collection and ambient-button techniques.
